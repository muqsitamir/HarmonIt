# ISBI 2027 manuscript

*Frozen Site-Probe Accuracy Is Not a Standalone Harmonization Score: An Audit of
Evaluation Practice for Multi-Site MRI*, a four-page paper for ISBI 2027.

| File | Contents |
| --- | --- |
| `main.tex`, `main.pdf` | Manuscript source and compiled PDF (four pages, including references) |
| `refs.bib` | References |
| `tables/table_main.tex` | Results table, generated by `scripts/isbi2027_tables.py` |
| `figures/` | `fig_probe_verdicts.pdf` from `scripts/isbi2027_figures.py`; `fig_qualitative_wide.pdf` (used), `fig_qualitative.pdf` and `fig_qualitative_rows2.pdf` (variants) from `scripts/isbi2027_qualitative.py` |
| `build.sh` | Builds `main.pdf` with pdflatex and bibtex (TinyTeX is enough) |
| `spconf.sty`, `IEEEbib.bst`, `strings.bib` | Official ISBI template files, identical to the ISBI 2027 kit (checked 2026-09-15) |
| `onepager.tex` | The template kit's one-page abstract example (unused) |
| `main_june2026.tex` | Superseded June 2026 benchmark draft; do not reuse its numbers |

Every number in the paper comes from the versioned results in
[`results/isbi2027`](../../results/isbi2027/README.md), which also lists the commands that
regenerate the table and figures. The protocol and its amendments are in
[`documentation/ISBI2027_PROTOCOL.md`](../../documentation/ISBI2027_PROTOCOL.md).
